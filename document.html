COPiPi クラス相互関係ドキュメント

このドキュメントは、DataViewForm と MemoForm を中心とした COPiPi の内部構造と相互関係を整理したものです。 メモデータは DataTable を介して共有され、各フォームは同じ DataRow を参照して動作します。

1. 全体構成

主要クラス
  • DataViewForm … メイン管理画面・トレイアイコン・メモ一覧・通知管理
  • MemoForm … 個々の付箋ウィンドウ（タイトル・本文・添付・通知など）
  • CircleButton … MemoForm 左上の丸ボタン（非表示＋通知状態表示）
  • SettingsForm … 設定画面（ファイル添付モードなど）※コード外部
データ構造

DataViewForm.mainData As DataTable が、全メモの共通データストアです。

  • id … メモの一意な ID（日時ベース）
  • title … メモタイトル
  • text … メモ本文
  • MemoColor … 色種別（0?5）
  • x, y … ウィンドウ位置
  • CollapsedFlag … 折り畳み状態
  • VisibleFlag … 表示／非表示
  • TopMostFlag … 最前面固定
  • FileReference … 添付ファイル／URL のパス文字列
  • RemindTime … 通知予定日時
  • FileType … None / Local / Original / URL

2. DataViewForm と MemoForm の関係

インスタンス生成とリンク
  • DataViewForm.Init() で mainData を読み込み、表示対象行に対して MemoBuild() を呼び出す。
  • MemoBuild(i As Integer) は mainData.Rows(i) を取得し、New MemoForm(row, Me) で MemoForm を生成。
  • MemoForm 側ではコンストラクタで MyRow = row と parentForm = parent を保持し、双方向リンクを形成。
DataRow の共有

各 MemoForm は MyRow As DataRow を通じて DataViewForm.mainData の行を直接参照します。 そのため、MemoForm 内で MyRow を更新すると、即座に共通 DataTable に反映されます。

  • タイトル変更：TitleText_Leave → MyRow("title") 更新 → parentForm.Save()
  • 本文変更：MemoText_Leave → MyRow("text") 更新 → 保存
  • 位置変更：WndProc(WM_EXITSIZEMOVE) → MyRow("x"), MyRow("y") 更新
  • 折り畳み：WndProc(WM_NCLBUTTONDBLCLK) → MyRow("CollapsedFlag") 更新
  • TopMost：WndProc(WM_NCRBUTTONUP) → MyRow("TopMostFlag") 更新
  • 通知日時：SaveRemindTime() → MyRow("RemindTime") 更新
  • 添付ファイル：MemoText_DragDrop / urlButton_Click → MyRow("FileReference"), MyRow("FileType") 更新

3. 表示制御の流れ

① メニューからの表示／非表示
  • DataViewForm.BuildShowCheckMenu() 色別にメモ一覧メニューを構築し、VisibleFlag に応じてチェック状態を設定。
  • 色単位切り替え：ShowColorMenu_Click
    • 対象色の行の VisibleFlag を一括更新。
    • 既存 MemoForm があれば Visible を切り替え、なければ MemoBuild() で生成。
    • メニューのチェック状態を同期し、Save() で XML に保存。
  • 個別切り替え：ShowSingleMemo_Click
    • 対象行の VisibleFlag を更新。
    • フォームが存在しなければ新規生成。
    • 親色メニューのチェック状態を再計算。
② MemoForm からの非表示操作
  • 左上丸ボタン：HideButton_Click
    • MyRow("VisibleFlag") = False に設定。
    • MemoForm 自身を Visible = False に。
    • parentForm.RebuildShowCheckMenu() と RecalculateColorMenuCheckState() でメニューを更新。

4. 通知機能の相互関係

① 通知日時の設定（MemoForm 側）
  • remindButton_Click
    • 既にラベルに日付がある場合 → MyRow("RemindTime") = DBNull.Value で解除。
    • 未設定の場合 → DateTimePicker を表示し、選択された日付を SaveRemindTime() で保存。
    • ラベル remindLabel に「次の通知日時：yyyy/MM/dd」を表示。
    • CheckReminder() で丸ボタン色を更新。
  • CreateRemindLabel / LoadRemindLabel MemoForm 表示時に DataRow の RemindTime をラベルに反映。
  • CheckReminder()
    • 期限到達 → hideButton.CircleColor = Red
    • 期限前 → 薄い青
    • 未設定 → 白
② 通知チェックとバルーン表示（DataViewForm 側）
  • Timer1_Tick → CheckAllReminders() を定期的に呼び出し。
  • CheckAllReminders() の処理：
    • 表示中の MemoForm に対して CheckReminder() を呼び出し、丸ボタン色を更新。
    • 全行を走査し、RemindTime が設定済みかつ DateTime.Now >= RemindTime のものを抽出。
    • 該当メモに対して：
      • 日付差分を計算し、「今日」または「超過（n 日）」を判定。
      • NotifyIcon1.BalloonTipTitle = "通知：yyyy/MM/dd"
      • NotifyIcon1.BalloonTipText = "title（今日／超過）" を設定し、バルーン表示。
      • VisibleFlag = True, TopMostFlag = True に設定。
      • 既存 MemoForm があれば TopMost = True とピン表示、なければ MemoBuild() で生成。
      • メニューを再構築し、色メニューのチェック状態を更新。
  • 通知確認ToolStripMenuItem_Click
    • RemindTime が設定されている行を抽出し、日付順にソート。
    • 「あと n 日／今日／超過（n 日）」を計算し、1件ずつダイアログ表示。

5. 添付ファイル／URL の相互関係

① 添付モード設定（SettingsForm → DataViewForm → MemoForm）
  • SettingsForm で選択されたモードを DataViewForm.SaveSetting("FileAttachMode") に保存。
  • DataViewForm.Init() で LoadSetting("FileAttachMode") を読み込み、FileAttachMode に反映。
  • MemoForm は parentForm.GetFileAttachMode() を通じて現在のモードを取得。
② ファイルドロップ（MemoForm → DataViewForm）
  • MemoText_DragDrop
    • モード LocalCopy → 専用フォルダ file に自動コピー。
    • モード UseOriginal / UseURL → ダイアログで「元ファイル参照」か「コピー保存」かを選択。
    • 結果を MyRow("FileReference") と MyRow("FileType") に保存。
    • parentForm.Save() で XML に永続化。
    • UI 側では fileLabel と clipLabel を更新。
  • FileLabel_Click
    • FileTypeEnum.Local / Original → ローカルファイルを Process.Start で開く。
    • FileTypeEnum.URL → ブラウザで URL を開く。
③ URL 添付（MemoForm 単独だが DataRow と連携）
  • urlButton_Click
    • 既存 URL がある場合 → 削除確認 → FileReference と FileType をクリア。
    • 未設定の場合 → InputBox で URL 入力 → IsValidUrl() で検証。
    • 有効な URL の場合 → MyRow("FileReference") と MyRow("FileType") = URL を保存。
    • GetUrlTitleSafe() で Web ページタイトルを取得し、成功時はメモタイトルにも反映。
    • 表示用には GetSmartUrlText() で短縮表示を生成し、fileLabel にセット。

6. 永続化と終了処理

XML 永続化
  • DataViewForm.Save() … mainData.WriteXml(Memo.xml) を実行。
  • 各種操作（タイトル変更・本文変更・位置変更・通知設定・添付変更・表示切替・削除など）で、必要に応じて Save() が呼ばれる。
  • DataViewForm_FormClosing でも最終的に XML へ書き出し。
終了処理
  • 右クリックメニュー「終了」 → 終了ToolStripMenuItem_Click → Save() → Application.Exit()
  • MemoForm 側でメモ削除後も、DataViewForm のメニュー状態を再計算して整合性を保つ。

7. まとめ

COPiPi は、1つの DataTable（mainData）を中心に、複数の MemoForm が同じ DataRow を共有する構造になっています。 DataViewForm は「一覧・通知・メニュー・永続化」を担当し、MemoForm は「個別編集・表示・添付・通知設定」を担当することで、 役割分担が明確になっています。

もしこのドキュメントをさらに細かく分割して「通知機能だけ」「添付機能だけ」の技術仕様書にしたくなったら、 その単位で別 HTML を作ることもできるよ。
